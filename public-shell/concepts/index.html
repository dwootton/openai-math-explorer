What the colors measure

Each prompt and each family’s title and description are represented by an EmbeddingGemma 2 vector. We calculate cosine similarity, then subtract that concept’s average score across all 372 families. All panels use the same color range and the same UMAP positions.

Gold means stronger-than-average alignment; blue means weaker-than-average alignment. This is not a probability, a truth score, or evidence of an opposite concept. Technique prompts describe language in the descriptions, not verified proof techniques. Choose a panel to inspect its exact prompt and raw scores.
